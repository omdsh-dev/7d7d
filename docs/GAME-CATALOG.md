# 7d7d 游戏能力目录

> 7d7d 能跑什么游戏？本文给出平台约束、可行玩法矩阵、已上线清单与投稿建议。
> 一句话结论：**单文件 HTML5 能承载的玩法，7d7d 基本都能承载；有合法来源的 Flash 小游戏可使用摘要锁定的同源 Ruffle 播放。**

## 平台约束（决定了"哪些游戏好做"）

| 约束 | 说明 | 对玩法的影响 |
|---|---|---|
| 单文件 HTML5 | 推荐 `<canvas>` + 原生 JS，≤100KB | 适合逻辑自包含的玩法；大型引擎（Unity/Phaser 全家桶）不适用 |
| 零外部依赖 | 不引 CDN 脚本/字体/图片 | 无素材库，画面以几何图形 + emoji 为主（也是一种风格） |
| 离线可玩 | iframe 为不透明 origin，localStorage 需 try/catch | 存档可用内存变量 + 页面内排行榜 |
| 输入 | 键盘（方向键/WASD/空格）、鼠标、触屏（pointer/touch 事件均可） | 键鼠类玩法全覆盖 |
| 音频 | WebAudio 可生成简单音效（无外部音频文件） | 打击感/反馈可做，音乐受限 |
| 并发 | 无网络请求 | 联机需服务端支持（见「进阶」） |

## Flash / Ruffle 兼容性

- **成熟（能玩）**：AS1/AS2 的绝大多数游戏——4399/7k7k 时代的小游戏主力（换装、打靶、祖玛、泡泡龙、黄金矿工类、动作过关）。
- **大部分可用**：AS3 常见玩法；个别渲染/音效差异属模拟器固有限制。
- **注意**：只接受用户自己拥有或已授权的 SWF；禁止搬运商业游戏资产。
- 播放页仅允许同源 Ruffle，不加载第三方 CDN；`pnpm fetch:ruffle` 固定 Ruffle 0.5.0，
  验证 npm registry SRI 与 5 个运行文件 SHA-256 后原子安装，任何差异都会安全失败。

## 给模型/作者的创作建议

1. **先选机制再选题材**：canvas 里一个"下落-拼接-消除"机制能套出十种题材；机制保底可玩性。
2. **30 秒上手**：开局 3 秒内可操作；页面要有操作提示文字。
3. **回合化 AI 对手**：五子棋式的"打分制 AI"（连子数×空位权重）几十行即可，观感远好于随机。
4. **一局 3 分钟内**：失败/通关都要有明确结束态 + 重开方式（Space/点击）。
5. **存档零成本**：`try { localStorage } catch {}` 包一层，高分榜白送。
6. **投稿**：放进 `community-games/<slug>/` + `node scripts/update-catalog.mjs`，PR 合并即全网同步。

## 进阶能力（路线图）

- **WebAudio 音效**：振荡器生成射击/消除/胜利音，零素材成本提升手感；
- **双人同屏**：一键盘+一鼠标即可做本地双人（贪吃蛇对战等）；
- **联机**：DSH webserver 的 `registerUpgrade` 路由可托管 WebSocket，做实时对战/合作；
- **WebGL**：零依赖下可用裸 WebGL 做粒子/光影效果（量力而行）；
- **封面自动截图**：headless 渲染 canvas 生成 cover.png，门户卡片更立体。
